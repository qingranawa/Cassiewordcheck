# 功能

## 检查与建议

主页支持实时输入、TXT 文本导入、CSV/Excel 词库导入、可用率统计和纯文本结果导出。结果提供内嵌、列表和两栏对比三种模式；不可用词可以点击查看相似建议并直接替换。

`Checker` 自动过滤 CASSIE 格式标签、标点、命名代号、北约代号、音高标记、颜色值和可选的中文字符。`SuggestionEngine` 使用通配、编辑距离和复合拆词策略生成建议。

## 词库管理

词库使用 `FrozenSet` 查询，支持默认词库、自定义 TXT 词库、批量导入、实时文件监控、搜索、字母/长度排序、词长与首字母分布、白名单和排除列表。两个词库可以进行新增、移除、共有词对比并导出差异报告。

## 历史与统计

最近 50 条检查快照保存到 `history.json`，重复输入自动去重，主页每 3 分钟自动保存一次。历史页可以恢复或清空快照，统计页展示检查次数、平均/最低覆盖率和不可用词趋势，字数页展示字符、单词、行数、词频和词长分布。

## 设置与本地化

设置页支持中文忽略、格式过滤、命名过滤、自动换行、字号、词库路径和语言切换。资源覆盖简体中文、English、日本語、한국어、Deutsch、Русский、Français、ไทย 共 8 种语言，页面导航会随语言即时更新。

## 数据兼容与发布

首次启动会把旧安装目录中的 `appsettings.json` 和 `history.json` 迁移到 MSIX `LocalFolder/data`，不会覆盖已经存在的用户数据。WinUI 单项目 MSIX 清单、图标和 x64 发布配置位于 `CassieWordCheck.WinUI`，`scripts/verify-winui-migration.ps1` 会执行测试、构建、解包和生产依赖扫描。
